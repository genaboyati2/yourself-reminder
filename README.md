## yourself-reminder

 # как это будет работать?
 - пользователь отправляет боту свое расписание, вносит какие-то правки, это расписание появляется на его экране в виде виджета. 
 - также на телефон будут приходить сообщения-напоминания о важных делах (бот бесплатный).

 #Как мы создавали бота(план)

1. 🤖 **Настройка:** создать бота в @BotFather, подготовить проект (Python + aiogram) и `.env` с токеном
2. 💾 **Хранение:** SQLite для пользователей и напоминаний, команды `/add`, `/list`, `/delete`
3. ⏰ **Отправка:** APScheduler по расписанию + разбор времени из текста («завтра в 18:00»)
4. 🚀 **Улучшения и деплой:** повторы, часовые пояса, кнопки «Отложить/Готово», запуск в Docker на сервере
